# Rules piled up — resolved

**What happened.** Every correction from the owner became a new rule. After a few weeks there
were about 150 across the rule files, and a large share of all commits changed the rules instead
of the product. Each rule was followed less reliably as the pile grew.
**What the owner expected.** That a miss leads to understanding: "update the base, don't think
of everything I say as a rule".
**Cause.** The Keeper was written as a rulebook, so the only way it could learn was by adding a
line. Adding felt like progress: the same making-without-thinking as elsewhere.
**What was changed.** The Keeper became a description of what it is and why. A miss now leads to
looking for earlier cases, asking what was expected, and modifying the text. Size limits stop
the files growing back.
